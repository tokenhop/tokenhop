# tokenhop — Agent Rules

The canonical agent rules for this repository live in [`CLAUDE.md`](CLAUDE.md).
This file exists so agent-runtime tools that default to `AGENTS.md` pick up the
same rules without duplicating prose. Do not edit this file except to add
agent-runtime-specific notes.

## Key commands

```bash
cp .env.example .env && npm install
npm run dev                        # dashboard + gateway on port 20127 (`-- --port N` to change)
npm run build && npm run start     # production, port 20127
npm run lint        # Biome via scripts/style.sh
npm run lint:fix    # auto-fix
npm run format      # format everything
npm test            # vitest + known-fails regression gate (needs tests/ deps)
```

Run tests only via `npm test`, from `tests/`, or with
`npx vitest run -c tests/vitest.config.js`. Without that config, `HOME` isn't
isolated and the tests delete real files under your home dir.

Commits follow Conventional Commits 1.0.0 (commitlint-enforced, see `.gitmessage`).
