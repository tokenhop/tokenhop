# v1.1.2 — 2026-10-23

## Summary

Second patch on the tokenhop 1.1 line: the Node.js October 21, 2026 security releases, pinned to Node 22.23.4, plus the recent high and critical npm advisories in undici, Next.js, DOMPurify, markdown-it and sharp.

## Highlights

- **Node.js**: the image, `.nvmrc` and CI runtime are Node 22.23.4, the patched 22.x release for the October 21, 2026 security advisories (#988).
- **Dependencies**: undici 7.30.1, Next.js 16.4.2, DOMPurify 3.4.17, markdown-it 14.3.3 and sharp 0.35.5 (#988).

## Breaking Changes

_None_

## Features

_None_

## Fixes

- **Security (Node)**: runtime pinned to 22.23.4 (`.nvmrc`, `node:22.23.4-alpine`, `node:22.23.4-bookworm`) and the server and test engines floor raised to `>=22.23.4` (#988).
- **Security (dependencies)**: undici 7.30.1, Next.js 16.4.2, DOMPurify 3.4.17, markdown-it 14.3.3 and sharp 0.35.5 (#988).

## Upgrade Notes

Swap the image (`ghcr.io/tokenhop/tokenhop:1.1.2`, or the floating `:1.1` / `:latest`) or update the CLI (`npm i -g tokenhop@1.1.2`). A source checkout of the server now requires Node >=22.23.4. The CLI package still declares `engines.node` `>=18.3.0`; those older runtimes do not include the October 21 Node fixes. No schema change.
