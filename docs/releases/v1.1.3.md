# v1.1.3 — 2026-11-03

## Summary

Third patch on the tokenhop 1.1 line: the remaining media, Vertex and Google catalog calls go through the connection proxy, Cloudflare image inputs use the hardened image fetcher, Codex re-authentication gets a clear message and replaces stale rows, and quota locks clear as soon as a usage poll shows headroom again.

## Highlights

- **Connection proxy**: image, embeddings and video requests, the Vertex token mint and the Google model catalogs honour the connection's proxy pool and Strict Proxy (#1000).
- **Codex re-authentication**: when every codex account needs re-authentication, clients get a `503` with `code: "reauth_required"` instead of a generic `404`, and reconnecting replaces the flagged row (#1032).
- **Quota locks**: a fresh positive usage poll releases GitHub and Codex quota locks, and Codex provider-reported resets are honoured instead of capped at 30 minutes (#1082).

## Fixes

- **Proxy**: image generation (main and retry requests, async polling, result downloads), embeddings, video (including the Vertex service-account token mint), the Google AI Studio, Gemini CLI and Antigravity catalogs, and the dev translator send route use the connection's proxy options. A Strict Proxy connection fails closed instead of calling the provider directly. The Vertex token cache is keyed on the full service-account credential (#1000).
- **Security (images)**: Cloudflare Workers AI image and mask inputs given as URLs are downloaded by the hardened image fetcher, with its address, size and image-type checks. An unfetchable URL returns a `400` with one generic message. The MITM host list matches exact hosts or subdomains only (#1003).
- **OAuth (Codex)**: all accounts flagged → `503` `All codex accounts need re-authentication. Reconnect them on the Providers page.` (`code: "reauth_required"`), and combos move to the next member immediately. Access-token-only rows are flagged on the first conclusive `401` (shown as "Token revoked"). A reconnect or re-import of the same account replaces its flagged row and keeps its id, name, priority and workspace (#1032).
- **Quota**: a fresh positive usage poll clears the persisted per-model quota lock for GitHub (including the monthly `402` limit) and Codex, and releases Antigravity exact-reset blocks. Codex provider-reported resets lock until the real reset time instead of retrying every 30 minutes (#1082).

## Upgrade Notes

Swap the image (`ghcr.io/tokenhop/tokenhop:1.1.3`, or the floating `:1.1` / `:latest`) or update the CLI (`npm i -g tokenhop@1.1.3`). No action required and no schema change. Clients that matched the old `404 No active credentials for provider: codex` should now handle `503` with `code: "reauth_required"`.
