## Backstop (full)

1. **Switch off + never-enabled = untouched**: no `keys/master` creation, no `workspaceKeys` rows, no marker, no envelopes, byte-identical writes, new routes 404 (D4; C10 asserts).
2. **Additive schema only**: new table, no rebuilds; shipped migrations frozen (`migrations/index.js` header rule); chain test guards shape.
3. **Pre-activation protected backup**: `protectedBackup` shape — private 0700 dir/0600 file, prune-exempt prefix; activation abort = zero mutation.
4. **Fail closed**: missing/wrong/corrupt KEK → sticky readiness reject; never regenerate, never plaintext fallback, never empty-credential substitute (D3).
5. **Crash-safe publication + rotation**: staged file → durable DB rewrap → atomic rename → finalize; restart recovery never infers commit from staging file alone (D8/D9).
6. **Import preflight**: prove root + authenticate wraps before any backup or wipe; wrong/missing KEK = zero mutation (D8; C4).
7. **Cleanup ordering**: WAL TRUNCATE + VACUUM only after encryption commit; durable cleanup-pending marker forces finish-on-restart before readiness (D7).
8. **Idempotence**: envelope-skip re-run; second activation performs no write (C3 byte-identity).
9. **Revert story**: before switch-on, everything is legacy; after activation, revert = restore pre-activation backup + old KEK (documented D7 limits: older copies stay plaintext by design).
10. **Baseline integrity**: no `known-fails.txt` additions; empty dependency diff `git diff origin/master -- package.json package-lock.json tests/package*.json cli/package.json` blocks merge.
