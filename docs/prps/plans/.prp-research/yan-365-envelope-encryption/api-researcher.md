| E6  | CSPRNG for keys/IVs                                        | <https://nodejs.org/docs/latest-v24.x/api/crypto.html#crypto_randombytes_size_callback>                                                                                               | "Generates cryptographically strong pseudorandom data" — DEK (32B), KEK (32B), IV (12B) all via `randomBytes` (OWASP Storage CS: CSPRNG for keys/IVs).                                                                           |

| E9  | Symlink refusal                                            | #fs_constants (O_NOFOLLOW)                                                                                                                                                            | "Flag indicating that the open should fail if the path is a symbolic link" — staging/publish paths use `O_RDONLY\|O_NOFOLLOW` / `wx` reads like `masterKey.js:79`.                                                               |

| E11 | Durability before publish                                  | #filehandlesync                                                                                                                                                                       | "Request that all data for the open file descriptor is flushed to the storage device" (POSIX fsync(2)) — fsync staged key bytes AND containing dir before/after publish; Windows: no dir fsync (masterKey.js:127-136 precedent). |

| E13 | Post-commit physical cleanup                               | <https://www.sqlite.org/wal.html> , <https://www.sqlite.org/lang_vacuum.html> (spec §External Dependencies)                                                                           | `PRAGMA wal_checkpoint(TRUNCATE)` + `VACUUM` lose freelist/WAL plaintext (D7); runner transaction precedent `migrations/index.js` header.                                                                                        |
| E14 | Envelope-encryption normative rules                        | OWASP Key Management CS (live 2026-10-06): "re-wrap stored Data Encryption Keys (DEKs) under the replacement KEK before destroying the old one.
